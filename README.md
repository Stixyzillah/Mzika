# Malawi Constitution Reader 🇲🇼📖

**Mzika** is a free, open-source web app that helps Malawians easily navigate the Constitution of Malawi.  
Most citizens don't have easy access to the law, and even when they do, it's hard to search or understand.  
This project makes it simple, fast, and mobile-friendly.

---

## ✨ Features
- Full text of the Malawi Constitution
- Search by keywords (e.g., "rights", "freedom", "land")
- Browse chapters and sections easily
- Mobile-friendly UI

---

## 🚀 How to Run
1. Clone the repo:
    ```
    git clone https://github.com/Stixyzillah/Mzika.git
    cd apf_reader
    ```

2. Install dependencies:
    ```
    pip install -r requirements.txt
    ```

3. Run the app:
    ```
    streamlit run app.py
    ```
